# AWS Load Balancer Web Server Project

This is a simple project to demonstrate how to deploy a basic web application on AWS using **EC2**, **Nginx**, with **Load Balancing**.

## 🚀 Project Goals
- Deploy a working web page
- Host it on EC2 instances
- Configure Nginx as a reverse proxy
- Set up a Load Balancer to distribute traffic

## 🧰 Tech Stack
- Amazon EC2
- Amazon Load Balancer
- Nginx
- SSH / CLI tools

## 🧪 What I Learned
- How to configure AWS Load Balancers
- Setting up a LEMP stack (Linux, Nginx, MariaDB, PHP)
- Handling web traffic routing with multiple servers
